# 🎬 Short Video Assistant

## 🎯 Objetivo do Projeto

O **Short Video Assistant** tem como objetivo simplificar e otimizar a rotina de criadores de conteúdo que trabalham com formatos de vídeo curto (Reels, TikTok, Shorts). A proposta do sistema é oferecer uma solução intuitiva para corte, processamento, organização e agendamento de postagens, utilizando notificações Web Push para alertar o momento exato da publicação e disponibilizar o arquivo pronto para envio.
